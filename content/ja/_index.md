## 猿思ネット洞察日報 2025/8/17

> 猿思 日報

### **AIコンテンツ要約**

```
Claude Codeが「学習モード」をローンチし、AI依存によるスキル低下を防ぐサポートを開始。Googleは軽量AIモデル「Gemma 3 270M」をオープンソース化、その高性能とデプロイの容易さが注目されている。OpenAIの壮大な計画には、数兆ドル規模の投資、脳コンピューターインターフェース（BCI）分野への進出などが含まれており、CEOのアルトマン氏はAIが重要な転換期にあると見ている。
新智元が10周年記念とASI時代の到来を祝い、AI関連の人材を募集中。Hi3DEval評価システムやAuto-RCAフレームワークなど、多数のオープンソースプロジェクトとAI技術の応用が進展。
AIの安全リスクについては、李飛飛氏がガバナンスと価値観に注目する一方、ヒントン氏は超知能の制御不能を懸念し、人類を気遣うAIの設計を提唱。新たなAI評価ベンチマーク「FormulaOne」では、トップクラスの大型モデルが軒並み「玉砕」する結果に。
```

### **今日のAIニュース**

1. 🤖🧠 **Claude Code** が、新たな **「学習モード」** をローンチしたよ！これは、AIに頼りすぎると陥る **「AI脳萎縮」** 問題を解決するためのもので、まるでプログラミングの「ジムトレーナー」みたいに、ユーザーに要所で手を動かすことを促し、本物のプログラミングスキル習得をサポートするんだ。

2. 🐯🚀 **Gemma 3 270M** は、Googleがオープンソース化した超軽量AIモデルなんだ！たった270Mのパラメータなのに、**指示への追従** や **テキスト構造化** のタスクで、もっと大きなモデルよりもすごいパフォーマンスを見せてるんだよ。低消費電力だからスマホやRaspberry Piみたいなデバイスでも動いちゃうし、軽くて速くてコスパの良いAIアプリ開発にぴったりだね。

3. 💰🌌 **OpenAI** のCEO、サム・アルトマン氏が、とんでもない壮大なビジョンを語ってくれたよ！彼はデータセンター建設や新型AIハードウェア開発に数兆ドルを投資し、さらには **脳コンピューターインターフェース（BCI）** 分野にまで進出し、検索やSNSをひっくり返す計画なんだって。彼曰く、今はインターネットバブル時代みたいなAIにとって超重要な時期で、GPT-5のリリースは「最高の時代であり、最悪の時代」の始まりを告げてるんだとか。

4. 🎉🥳 新智元、なんと10周年記念祭＆ASI時代突入！新智元は今、AI産業レポートの主筆、上級ビデオエディター、上級エディター/エディター、そしてエディターインターンなど、様々な職種でAI大好きなキミの参加を待ってるよ！[🔗 新智元招聘情報](此处应插入新智元官网招聘链接，原文未提供)

5. 😎 **Hi3DEval** は、上海人工知能研究所が複数の大学と共同で開発した、超科学的で超包括的な3D生成品質評価システムなんだ！オブジェクトレベル、パーツレベル、マテリアルテーマの三層評価プロトコルを使って、3Dモデルの全体的な形状、局所構造、マテリアルのリアルさまで多角的に分析しちゃうよ。[🔗 Hi3DEvalプロジェクトページ](https://zyh482.github.io/Hi3DEval/) [🔗 3D生成ランキング](https://huggingface.co/spaces/3DTopia/3DGen-Leaderboard)

6. 💪 **build-your-own-x** というGitHubプロジェクト、これ、ゼロからいろんな技術を構築する学習パスを提供してくれるんだ！実践しながらプログラミングスキルをガッツリ習得したい人にはたまらないね。[🔗 プロジェクトリポジトリ](https://github.com/codecrafters-io/build-your-own-x)

7. 🚀 **90DaysOfCyberSecurity** は、90日間でサイバーセキュリティをマスターするための学習プランを提供してるよ！基礎認証から高度なテクニックまで、サイバーセキュリティのあらゆる側面を網羅してるから、これで君もサイバーの達人だ！[🔗 プロジェクトリポジトリ](https://github.com/farhanashrafdev/90DaysOfCyberSecurity)

8. 🍎 **awesome-mac** 、これはMacユーザーにはたまらないお宝リポジトリ！Mac上のいろんな素晴らしいソフトウェアがぎゅっと詰まってるんだよ。[🔗 プロジェクトリポジトリ](https://github.com/jaywcjlove/awesome-mac)

9. 🤖 **parlant** は、大規模言語モデル (LLM) のアプリケーションをめちゃくちゃシンプルにしてくれるLLMエージェントだよ！デプロイも使うのも超簡単なんだ。[🔗 プロジェクトリポジトリ](https://github.com/emcie-co/parlant)

10. 🤔 **magic** 、これはAIエージェント、ワークフローエンジン、IM、オンライン共同作業システムが全部一体になったオープンソースのAI生産性プラットフォームなんだ！[🔗 プロジェクトリポジトリ](https://github.com/dtyq/magic)

11. 🤯 DeepMindの主席科学者デニー・ジョウ氏が、スタンフォードCS25の授業で**大規模言語モデル(LLM)**の推論メカニズムを解説してくれたよ！彼曰く、LLMの推論は一連の **「中間トークン」** を生成することで実現されていて、強化学習によるファインチューニングなどの技術についても深く掘り下げていたんだ。[▶️ 動画デモ](https://www.youtube.com/watch?v=ebnX5Ur1hBk)

12. 🤖 李飛飛氏とヒントン氏、AIの安全性に関する見解がちょっと違うんだ。李飛飛氏は **「デザイン、ガバナンス、価値観」** に注目してるけど、ヒントン氏は超知能の制御不能を懸念して「**人類を気遣うAI** 」を設計すべきだと提唱してるんだよ。「目標の誤った汎化」と「道具の収斂」が、AIの潜在的リスクにおける二大核心概念なんだって。

13. 🤔 **FormulaOne** は、新しいAI評価ベンチマークなんだけど、これがすごいんだ！220問のグラフ構造動的計画法問題を含んでて、GPT-5みたいなトップクラスの大型モデルまで全部「コケて」、スコアはまさかのゼロだったんだって！[FormulaOne](https://image.jiqizhixin.com/uploads/editor/656fe086-cbec-46b3-b135-a600f7a68fda/640.png) [🔗 FormulaOneリーダーボード](https://huggingface.co/spaces/double-ai/FormulaOne-Leaderboard)
