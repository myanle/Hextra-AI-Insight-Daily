## 猿思ネット洞察日報 2025/8/17

> 猿思 日報 📝

### **AIコンテンツ概要**

```
Claude Codeが「学習モード」を発表し、AI依存によるスキル低下を防ぐサポートを開始。Googleは軽量大規模モデル「Gemma 3 270M」をオープンソース化し、その優れた性能と簡単なデプロイが注目される。OpenAIのサム・アルトマンCEOは、数兆ドル規模の投資、脳神経インターフェースへの進出、検索やソーシャルメディアの変革といった壮大な青写真を描き、AIの発展が重要な時期にあると語る。
新智元（Xinzhiyuan）は10周年を迎え、ASI時代に突入し、AI関連の人材を募集中。Hi3DEval評価システムやAuto-RCAフレームワークなど、多数のオープンソースプロジェクトとAI技術の応用が進展。
李飛飛（Li Feifei）氏とヒントン（Hinton）氏の間でAI安全リスクに関する意見の相違が見られ、李氏はガバナンスを重視する一方、ヒントン氏は超知能の暴走を懸念。新しいAI評価ベンチマーク「FormulaOne」では、トップレベルの大規模モデルが軒並み"撃沈"し、全モデルがゼロ点という結果に終わった。
```

### **今日のAIニュース**

1.  **Claude Code**が新しい「学習モード」をローンチしました！💡 これ、長期的なAI依存による「AI脳萎縮」問題を解決するために開発されたんだって。直接答えを教えるんじゃなくて、まるでプログラミングのパーソナルトレーナーみたいに、ユーザーを要所で立ち止まらせて、自分でタスクを完遂させることで、ちゃんとプログラミングスキルを身につけられるようにガイドしてくれるそう。学習効果アップに期待できそう！📚
2.  **Google**がオープンソース化した軽量大規模モデル「Gemma 3 270M」がすごい！🌟 パラメータ数はたったの270Mなのに、「指示にちゃんと従う」タスクや「テキストを構造化する」タスクで、もっと大きなモデルを上回るほどのパフォーマンスを発揮してるんだとか。消費電力が少ないから、スマホやラズベリーパイみたいなデバイスでも動いちゃうし、軽くて速くてコスト効率の良いAIアプリを作るのにピッタリだね📱。
3.  **OpenAI**のサム・アルトマンCEOが、OpenAIの壮大な青写真を披露！🚀 なんと、データセンター建設や新型AIハードウェア開発に数兆ドル規模の投資をしたり、さらには「脳神経インターフェース」分野にも進出して、検索やソーシャルメディアを根底からひっくり返す計画なんだって。彼は、今のAIはまるでインターネットバブル時代みたいに重要なフェーズにあると感じていて、GPT-5のリリースは「最高の時代であり、最悪の時代でもある」と語っています。未来がどうなるか、ドキドキするね！🔮
4.  **新智元（Xinzhiyuan）**が設立10周年を迎え、ASI（汎用人工知能）時代が幕を開けたよ！🎉 新智元では、AI産業レポートの主筆、上級ビデオエディター、上級エディター/エディター、エディターインターンなど、様々なポジションでAIを愛する才能を募集中なんだって。興味ある人はぜひチェックしてみて！✨ [🔗 新智元採用情報](此处应插入新智元官网招聘链接，原文未提供)
5.  **上海人工知能研究所**が複数の大学と共同で発表した**Hi3DEval**は、より科学的で包括的な3D生成品質評価システム！📐 オブジェクトレベル、パーツレベル、マテリアルテーマの三層評価プロトコルを採用して、3Dモデルの全体的な形状、局所的な構造、マテリアルのリアルさを多角的に分析するんだって。すごいこだわりようだね！✨ [🔗 Hi3DEvalプロジェクトページ](https://zyh482.github.io/Hi3DEval/) [🔗 3D生成ランキング](https://huggingface.co/spaces/3DTopia/3DGen-Leaderboard)
6.  **GitHubプロジェクト「build-your-own-x」**は、ゼロから様々な技術を構築するための学習パスを提供してるよ。🛠️ これを使えば、実践を通じてプログラミングスキルをしっかりマスターできそう！まさに宝の山だね。📚 [🔗 プロジェクトリポジトリ](https://github.com/codecrafters-io/build-your-own-x)
