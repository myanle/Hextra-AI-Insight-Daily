### 今日のAIニュース

1. Claude Code が新しい **「学習モード」** をリリースしたよ！🎉 これは、AIに頼りすぎると起きる **「AI脳萎縮」** 問題を解決するのが狙いなんだ。答えをポンと出すんじゃなくて、まるでプログラミングのパーソナルトレーナーみたいに、肝心なところで立ち止まって自分でコードを書かせたりするんだ。そうすることで、本当にプログラミングスキルが身につくってわけ！

2. Gemma 3 270M がGoogleからオープンソース化されたよ！✨ これ、たった270Mのパラメータしかない超軽量な大規模モデルなのに、**指示への追従** とか **テキスト構造化** のタスクでは、なんと一部のデカいモデルよりも良い成績を出すんだって！しかも、消費電力が少ないから、スマホやRaspberry Piみたいなデバイスでもサクサク動いちゃう。軽くて速くて、しかもコストを抑えたAIアプリを作るのにマジで最適だね！

3. OpenAI のCEO、サム・アルトマンがOpenAIの壮大な未来図をぶち上げたよ！💸 なんと、データセンター建設や新型AIハードウェア開発に数兆ドル規模の投資をするって話で、さらには **脳コンピューターインターフェース** の領域まで攻め込んで、検索やソーシャルメディアを根底から変えちゃう計画なんだとか。アルトマンは、今のAIはインターネットバブルみたいなすっごく大事な時期にいるって言ってて、GPT-5のリリースは「最高の時代であり、最悪の時代でもある」っていうのを象徴してるって感じだね！

4. 新智元 が10周年記念イベントでASI時代の幕開けを祝ってるよ！🎊 しかも、AI産業レポートのチーフライター、シニアビデオエディター、シニアエディター／エディター、それにエディターインターンとか、AI好きにはたまらない求人がいっぱいあるみたい。AIへの情熱があるなら、ぜひ応募してみてね！ [🔗 新智元採用情報](此处应插入新智元官网招聘链接，原文未提供)

5. Hi3DEval は、上海人工知能研究所と複数の大学が一緒に作った、めっちゃ科学的でオールマイティな3D生成品質評価システムなんだ！👍 オブジェクトレベル、パーツレベル、マテリアルテーマっていう3段階の評価プロトコルを使って、3Dモデルの全体の形、細かい構造、そして材質のリアルさをいろんな角度からバッチリ分析してくれるよ！ [🔗 Hi3DEvalプロジェクトページ](https://zyh482.github.io/Hi3DEval/) [🔗 3D生成ランキング](https://huggingface.co/spaces/3DTopia/3DGen-Leaderboard)
