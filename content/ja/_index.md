## 猿思ネット洞察日報 2025/8/17

> 猿思日報

### **AIコンテンツ要約**

`Claude Code` は `「学習モード」` をリリースし、`AI` 依存によるスキル低下を防ぎます。`Google` は軽量な大規模モデル `Gemma 3 270M` をオープンソース化し、優れた性能と簡単なデプロイメントを実現。`OpenAI` の壮大な計画には、巨額投資やブレイン・マシン・インターフェースなどが含まれ、`Altman` は `AI` 開発が重要な時期にあると見ています。`新智元` の `10` 周年記念イベントでは `ASI` 時代が始まり、同時に `AI` 関連人材を募集。`Hi3DEval` 評価システムや `Auto-RCA` フレームワークなど、多数のオープンソースプロジェクトと `AI` 技術の応用が進んでいます。`Li Feifei` と `Hinton` は `AI` 安全リスクについて異なる見解を持っており、前者はガバナンスを重視し、後者は超知能の制御不能を懸念しています。新しい `AI` 評価ベンチマーク `FormulaOne` は、トップクラスの大規模モデルを「転倒」させました。

### **今日のAIニュース**

1.  `Claude Code` が、`AI` への長期的な依存による「AI脳委縮」問題を解決するため、`"学習モード"` を新たにリリースしたよ！🎉 このモードは、答えを直接教えるのではなく、プログラミングの「フィットネストレーナー」みたいに、ユーザーに重要なステップで立ち止まらせて、実際に手を動かしてタスクを完了させることで、プログラミングスキルを真に習得できるように導いてくれるんだ。

2.  `Google` がオープンソース化した軽量大規模モデル `Gemma 3 270M` は、なんとパラメータ数がたったの `270M`！😲 それなのに、`指示への追従` や `テキスト構造化` のタスクでは、もっと大規模なモデルを凌ぐほどの優れたパフォーマンスを発揮しているんだ。消費電力も低いから、スマホや `Raspberry Pi` なんかのデバイスでも動いちゃう。軽量で高速、低コストな `AI` アプリケーションを構築するのにピッタリだね！✨

3.  `OpenAI` の `CEO`、`Altman` 氏が `OpenAI` の壮大なビジョンを語ってくれたよ！🚀 数兆ドルを投資してデータセンターを建設し、新型 `AI` ハードウェアを開発、さらには `ブレイン・マシン・インターフェース` の分野にも参入して、検索やソーシャルメディアをひっくり返す計画らしいんだ。彼は、今の `AI` はインターネットバブルの頃に似た、まさに重要な時期にあると見ていて、`GPT-5` のリリースは「最高の時代であり、最悪の時代でもある」ことを象徴しているってさ。🤯

4.  `新智元` は `10` 周年を迎え、`ASI` 時代の幕開けを祝うイベントを開催！✨ `AI` 産業の報道主任記者、上級ビデオ編集者、上級編集者/編集者、編集インターンなど、様々なポジションで `AI` 大好きな君の参加を募集してるよ！ぜひチェックしてみてね！👉 `[🔗 新智元の求人情報](此处应插入新智元官网招聘链接，原文未提供)`

5.  `Hi3DEval` は、`上海人工知能研究所` が複数の大学と共同で開発した、より科学的で包括的な `3D生成品質評価システム` だよ！🔍 オブジェクトレベル、パーツレベル、マテリアルテーマという `3` 層の評価プロトコルを採用して、`3Dモデル` の全体的な形状、局部構造、マテリアルのリアルさなどを多角的に分析してくれるんだ。これはすごい！`[🔗 Hi3DEvalプロジェクトページ](https://zyh482.github.io/Hi3DEval/)` `[🔗 3D生成ランキング](https://huggingface.co/spaces/3DTopia/3DGen-Leaderboard)`

6.  `GitHub` プロジェクト `「build-your-own-x」` は、ゼロから様々な技術を構築する学習パスを提供してるんだ！🛠️ 実践を通じてプログラミングスキルを習得するのに役立つよ。`[🔗 プロジェクトリポジトリ](https://github.com/codecrafters-io/build-your-own-x)`

7.  `90DaysOfCyberSecurity` は、`90日間` でサイバーセキュリティを網羅的に学べる学習プランだよ！🛡️ 基礎的な認証から高度なテクニックまで、サイバーセキュリティのあらゆる側面をカバーしているんだ。`[🔗 プロジェクトリポジトリ](https://github.com/farhanashrafdev/90DaysOfCyberSecurity)`

8.  `awesome-mac` は、`Mac` のクールなソフトウェアをたくさん集めた、`Mac` ユーザーにとってのまさに宝物のようなリポジトリだよ！💎 `[🔗 プロジェクトリポジトリ](https://github.com/jaywcjlove/awesome-mac)`

9.  `parlant` は、大規模言語モデル (`LLM`) アプリケーションをシンプルにする `LLM` エージェントで、デプロイも使い方もとっても簡単なんだ！🤖✨ `[🔗 プロジェクトリポジトリ](https://github.com/emcie-co/parlant)`
