## サルシンネット洞察日報 2025/8/17

> サルシン日報

### **AIコンテンツ概要**

```
Claude Codeが「学習モード」を発表し、AI依存によるスキル低下を防ぐサポートを開始！Googleは軽量ながら高性能なAIモデル「Gemma 3 270M」をオープンソース化し、デプロイが超簡単に。OpenAIのサム・アルトマンCEOは、データセンターや新型AIハードウェアへの巨額投資、脳コンピューターインターフェースへの進出など壮大なビジョンを語り、「AIは今、まさに重要なフェーズにいる」と力説。
新智元は10周年記念式典とASI時代の幕開けを祝い、AI関連の人材を募集中！Hi3DEval評価システムやAuto-RCAフレームワークなど、多数のオープンソースプロジェクトやAI技術の進化も続々登場。
李飛飛氏とHinton氏の間でAIの安全リスクに関する見解の相違が。李氏はガバナンスを重視する一方、Hinton氏は超知能の制御不能化を懸念。新AI評価ベンチマーク「FormulaOne」では、GPT-5を含むトップAIモデルがまさかの全問不正解で撃沈！
```

### **今日のAIニュース**

1.  🚀 **Claude Code** が、AIへの過度な依存による「AI脳萎縮」問題を解決するため、新機能「**学習モード**」をローンチしたよ！このモードは直接答えを教えるんじゃなくて、まるでプログラミングの「ジムトレーナー」みたいに、ユーザーに要所で立ち止まって手を動かすよう促すんだ。これで、真のプログラミングスキルが身につくってわけだね！

2.  ✨ **Google** がオープンソース化した軽量AIモデル「**Gemma 3 270M**」がすごいんだ！たった270Mのパラメータ数なのに、**指示への追従**や**テキスト構造化**タスクで素晴らしいパフォーマンスを発揮し、大規模モデルをも凌駕するほど。低消費電力だからスマホやラズベリーパイみたいなデバイスでも動いちゃうし、軽くて速くてコストも抑えられるAIアプリを作るのにぴったりだね！

3.  💰 **OpenAI** のCEO、サム・アルトマン氏が、OpenAIの超壮大な未来図を語ってくれたよ！数兆ドルを投じてデータセンターを建設し、新型AIハードウェアを開発するんだって。さらに、**脳コンピューターインターフェース**分野にも進出し、検索やSNSをひっくり返す計画らしい。アルトマン氏は、「今のAIは、インターネットバブルの時代みたいに、まさにターニングポイントだ。GPT-5の登場は『最高の時代であり、最悪の時代』の幕開けを告げるものだ」と熱く語っているよ！

4.  🎉 **新智元** が10周年記念イベントとASI時代の幕開けを盛大に祝ったよ！AI産業レポーター、シニア動画エディター、シニアエディター/エディター、エディターインターンなど、様々なポジションでAI好きの人材を募集中！ぜひ飛び込んでみてね！[🔗 新智元の採用情報](此处应插入新智元官网招聘链接，原文未提供)

5.  ✨ **上海AIラボ** が複数の大学と共同で、より科学的で包括的な3D生成品質評価システム「**Hi3DEval**」を発表したよ！オブジェクトレベル、パーツレベル、マテリアルテーマの3層評価プロトコルを採用して、3Dモデルの全体的な形状、局所構造、マテリアルのリアルさを多角的に分析できるんだ。これはマジでスゴい！[🔗 Hi3DEvalプロジェクトページ](https://zyh482.github.io/Hi3DEval/) [🔗 3D生成リーダーボード](https://huggingface.co/spaces/3DTopia/3DGen-Leaderboard)

6.  🛠️ **GitHub** の「**build-your-own-x**」プロジェクトは、色々な技術をゼロから構築できる学習パスを提供してくれるんだ。手を動かしながらプログラミングスキルを習得するのに超役立つよ！[🔗 プロジェクトリポジトリ](https://github.com/codecrafters-io/build-your-own-x)

7.  🔒 「**90DaysOfCyberSecurity**」は、90日間のサイバーセキュリティ学習プランを提供しているんだ。基礎的な認証から高度なテクニックまで、サイバーセキュリティのあらゆる側面を網羅しているから、スキルアップしたい人は要チェック！[🔗 プロジェクトリポジトリ](https://github.com/farhanashrafdev/90DaysOfCyberSecurity)

8.  🍎 「**awesome-mac**」は、Mac用の様々なハイクオリティなソフトウェアを集めた、まさにMacユーザーにとっての宝の山みたいなリポジトリだよ！[🔗 プロジェクトリポジトリ](https://github.com/jaywcjlove/awesome-mac)

9.  🤖 「**parlant**」は、大規模言語モデル (LLM) アプリケーションをシンプルにしてくれるLLMエージェントなんだ。デプロイも使い方も超簡単だから、LLM開発者には朗報だね！[🔗 プロジェクトリポジトリ](https://github.com/emcie-co/parlant)

10. ✨ 「**magic**」は、AIエージェント、ワークフローエンジン、IM、オンライン共同作業システムが統合されたオープンソースのAI生産性プラットフォームだよ！これ一つで作業効率が爆上がりするかも！？[🔗 プロジェクトリポジトリ](https://github.com/dtyq/magic)

11. 🧠 **DeepMind** の主任科学者Denny Zhou氏が、スタンフォード大学CS25の授業で**大規模言語モデル (LLM)** の推論メカニズムについて超分かりやすく解説してくれたよ！LLMの推論は、一連の**中間トークン**を生成することで実現されるって指摘しつつ、強化学習による微調整なんかの技術についても深掘りしてるんだ。これは必見！[▶️ 動画デモ](https://www.youtube.com/watch?v=ebnX5Ur1hBk)

12. 🗣️ **李飛飛氏** と **Hinton氏** の間で、AIの安全問題に関する見解にちょっとした違いがあるんだ。李氏は**デザイン、ガバナンス、そして価値観**に焦点を当てているのに対し、Hinton氏は超知能の制御不能化を懸念して、**人類を気遣うAI**を設計すべきだと提言しているよ。「目標の誤った汎化」と「ツールの収束」が、AIの潜在的リスクにおける二大核心概念だってさ。

13. 🤯 **FormulaOne** という新しいAI評価ベンチマークが登場したんだけど、これがヤバいんだ！220問のグラフ構造動的計画法問題が含まれていて、なんとGPT-5を含むトップAIモデルが**全部「コケて」**、成績はまさかのゼロ！これは衝撃だね！[FormulaOne](https://image.jiqizhixin.com/uploads/editor/656fe086-cbec-46b3-b135-a600f7a68fda/640.png) [🔗 FormulaOne Leaderboard](https://huggingface.co/spaces/double-ai/FormulaOne-Leaderboard)
