## 猿思ネット洞察日報 2025/8/17

> 猿思 日報

### **AIコンテンツ概要**

```
Claude Codeが「学習モード」を発表。AI依存によるスキル低下を防ぐ狙い。Googleは軽量大規模モデルGemma 3 270Mをオープンソース化。高性能でデプロイも容易。OpenAIは巨額投資やBMIを含む壮大な構想を提示。アルトマンCEOはAI発展を重要な時期と認識。
新智元は10周年記念式典とASI時代の幕開けを祝し、AI関連人材を募集。Hi3DEval評価システムやAuto-RCAフレームワークなど、多数のオープンソースプロジェクトとAI技術の応用が進展中。
李飛飛氏とヒントン氏はAIの安全リスクについて異なる見解。前者はガバナンスを重視し、後者は超知能の暴走を懸念。新しいAI評価基準FormulaOneで、最先端の大規模モデルが「失敗」する結果に。
```

### **今日のAIニュース**

1. ✨ **Claude Code** が、長期的なAI依存による「AI脳萎縮」問題を解決するために、まったく新しい**「学習モード」**をリリースしたよ！このモードは、ただ答えを教えるんじゃなくて、まるでプログラミングのパーソナルトレーナーみたいに、重要なステップでユーザーに立ち止まってもらい、実際に手を動かしてタスクを完遂させることで、真のプログラミングスキルを身につけられるように導いてくれるんだ。すごいね！

2. 🚀 **Gemma 3 270M** が、Googleからオープンソースで公開されたんだ！たった270Mの軽量モデルなのに、**指示への追従**や**テキスト構造化**タスクで素晴らしいパフォーマンスを発揮してて、一部のもっと大規模なモデルすら超えちゃうほどらしいよ。低消費電力だからスマホやラズベリーパイみたいなデバイスでも動いちゃうし、軽くて速くてコストも抑えられるAIアプリを作るのにぴったりだね！

3. 🌠 **OpenAI** のCEO、アルトマン氏がOpenAIの壮大な未来図を語ったよ！なんと数兆ドルを投資してデータセンターを建設し、新しいAIハードウェアを開発、さらには**脳機インターフェース**の分野にまで進出して、検索やソーシャルメディアをひっくり返す計画なんだって。彼は、今のAIはインターネットバブルのような重要な時期にいると考えていて、GPT-5のリリースは「最高の時代であり、最悪の時代でもある」ことの象徴だと言ってるよ。

4. 🥳 **新智元** が10周年記念式典を開催して、ASI（汎用人工知能）時代が幕を開けたよ！新智元では、AI産業レポート主筆、シニアビデオエディター、シニアエディター／エディター、エディターインターンなど、たくさんのポジションでAIが大好きな君を大募集中！ぜひジョインしてね！[🔗 新智元採用情報](此处应插入新智元官网招聘链接，原文未提供)

5. ✨ **Hi3DEval** って知ってる？これは上海AI研究所が複数の大学と共同で開発した、もっと科学的で包括的な3D生成品質評価システムなんだ。オブジェクトレベル、パーツレベル、マテリアルテーマの3層評価プロトコルを採用してて、3Dモデル全体の形状、局所構造、マテリアルのリアルさを多角的に分析してくれるよ！すごいね！[🔗 Hi3DEvalプロジェクトページ](https://zyh482.github.io/Hi3DEval/) [🔗 3D生成リーダーボード](https://huggingface.co/spaces/3DTopia/3DGen-Leaderboard)

6. 🛠️ **build-your-own-x** っていうGitHubプロジェクト、知ってる？これはゼロからいろんな技術を構築する学習パスを提供してて、ユーザーが実践を通じてプログラミングスキルを習得するのを助けてくれるんだ！めちゃくちゃ役立つよ！[🔗 プロジェクトリポジトリ](https://github.com/codecrafters-io/build-your-own-x)

7. 🔐 **90DaysOfCyberSecurity** は、90日間のサイバーセキュリティ学習プランを提供してるよ！基礎認証から高度なテクニックまで、サイバーセキュリティのあらゆる側面をカバーしてるんだ。これは見逃せないね！[🔗 プロジェクトリポジトリ](https://github.com/farhanashrafdev/90DaysOfCyberSecurity)

8. 🍎 **awesome-mac** は、Mac上のいろんなすごいソフトウェアを集めてるんだ！Macユーザーにとってはまさに宝の山、必見のリポジトリだよ！[🔗 プロジェクトリポジトリ](https://github.com/jaywcjlove/awesome-mac)

9. 🤖 **parlant** は、大規模言語モデル（LLM）のアプリケーションをめちゃくちゃシンプルにしてくれるLLMエージェントだよ！デプロイも使うのも超簡単なんだ。LLM使ってる人には朗報だね！[🔗 プロジェクトリポジトリ](https://github.com/emcie-co/parlant)

10. ✨ **magic** っていうオープンソースのAI生産性プラットフォームが登場したよ！AIエージェント、ワークフローエンジン、IM、オンライン共同作業システムが全部一つになってるんだ。これはすごい生産性向上ツールになりそうだね！[🔗 プロジェクトリポジトリ](https://github.com/dtyq/magic)

11. 🧠 **DeepMindの主席科学者デニー・チョウ氏**が、スタンフォードCS25の授業で**大規模言語モデル（LLM）**の推論メカニズムについて解説してくれたよ！LLMの推論は、一連の**中間トークン**を生成することで実現されるんだって。強化学習によるファインチューニングなどの技術についても掘り下げてくれたから、めちゃくちゃ興味深い内容だったよ！[▶️ 動画デモ](https://www.youtube.com/watch?v=ebnX5Ur1hBk)

12. 🤔 **李飛飛氏とヒントン氏**が、AIの安全問題について異なる見解を示してるんだ。李飛飛氏は**デザイン、ガバナンス、そして価値観**に注目してるんだけど、ヒントン氏は超知能の暴走を懸念していて、**人間を気遣うAI**を設計すべきだと提言してるんだよ。「目標の誤った汎化」と「ツールの収斂」がAIの潜在的リスクにおける二大核心概念だって。なるほどね！

13. 🤯 **FormulaOne** という新しいAI評価基準が登場したんだけど、これがまたすごいやつなんだ！220問のグラフ構造動的計画法問題が含まれてて、GPT-5みたいなトップクラスの大規模モデルでさえ、なんと全問「失敗」、スコアは全部ゼロだったらしいよ！これは衝撃だね！[FormulaOne](https://image.jiqizhixin.com/uploads/editor/656fe086-cbec-46b3-b135-a600f7a68fda/640.png) [🔗 FormulaOne リーダーボード](https://huggingface.co/spaces/double-ai/FormulaOne-Leaderboard)
