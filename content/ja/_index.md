## 猿思ネット洞察日報 2025/8/17

> `猿思日報`

```
Claude CodeがAI依存によるスキル低下を防ぐ「学習モード」を発表。Googleは軽量大規模モデル「Gemma 3 270M」をオープンソース化し、優れた性能と簡単な展開を実現。OpenAIのサム・アルトマンCEOは、巨額投資、BMI（ブレイン・マシン・インターフェース）など壮大な計画を掲げ、AI発展の正念場と認識。
新智元は設立10周年記念でASI時代を宣言し、AI関連人材を募集。Hi3DEval評価システムやAuto-RCAフレームワークなど、多数のオープンソースプロジェクトとAI技術が進展。
```

### **今日のAIニュース**

1.  Claude Code が、AIへの長期的な依存による「AI脳萎縮」問題を解決するために、まったく新しい「学習モード」を発表したよ！🤖🧠 このモードは、直接答えを教えるんじゃなくて、まるでプログラミングの「フィットネスパーソナルトレーナー」みたいに、ユーザーが重要なステップで一旦立ち止まって、自分でタスクを完了するように導いてくれるんだ。そうすることで、プログラミングスキルを本当に習得できるってわけ。

2.  Googleがオープンソース化した「Gemma 3 270M」は、パラメータ数がたった270Mしかない超軽量大規模モデルなんだ！🐯🚀だけど、このモデル、命令に従うタスクやテキスト構造化のタスクで驚くほど優秀なパフォーマンスを発揮してて、なんと一部の大型モデルさえも凌駕しちゃうんだよ。消費電力が低いから、スマホやRaspberry Piみたいなデバイスでもサクサク動かせちゃって、軽くて速くて低コストなAIアプリを作るのにピッタリなんだよね。

3.  OpenAIのCEOであるサム・アルトマン氏が、OpenAIの壮大な未来像を描いたんだよ！💰🌌 何兆ドルもの巨額を投じてデータセンターを建設し、新型AIハードウェアを開発するだけじゃなく、なんと「脳機インターフェース」の分野にも参入して、検索やソーシャルメディアの常識をひっくり返そうと計画してるんだって。彼は、今のAIはインターネットバブルの頃に似た、まさに「鍵となる時期」にあると考えていて、GPT-5の発表は「最高の時代であり、最悪の時代でもある」ことの象徴だと語っているよ。

4.  新智元が設立10周年記念イベントで、ASI（汎用人工知能）時代を盛大に開幕したよ！🎉🥳 そして、AI産業レポートの主任記者、上級ビデオエディター、上級エディター/エディター、エディターインターンなど、様々な職種でAIをこよなく愛する人材を募集しているんだ。ぜひ、君も新智元にジョインしてみない？！[🔗 新智元採用情報](此处应插入新智元官网招聘链接，原文未提供)

5.  「Hi3DEval」は、上海人工知能研究所が複数の大学と共同で発表した、より科学的で包括的な3D生成品質評価システムなんだ！😎 オブジェクトレベル、パーツレベル、材質テーマという三層の評価プロトコルを採用してて、3Dモデルの全体的な形状、局所的な構造、材質のリアルさを多角的に分析してくれるんだよ。[🔗 Hi3DEvalプロジェクトページ](https://zyh482.github.io/Hi3DEval/) [🔗 3D生成ランキング](https://huggingface.co/spaces/3DTopia/3DGen-Leaderboard)

6.  「build-your-own-x」というGitHubプロジェクトは、ゼロから様々なテクノロジーを構築する学習パスを提供してくれるんだ！💪 実際に手を動かしながらプログラミングスキルを習得するのに役立つよ。[🔗 プロジェクトリポジトリ](https://github.com/codecrafters-io/build-your-own-x)

7.  「90DaysOfCyberSecurity」は、90日間のサイバーセキュリティ学習プランを提供しているんだ！🚀 基礎的な資格取得から高度なテクニックまで、サイバーセキュリティのあらゆる側面を網羅しているよ。[🔗 プロジェクトリポジトリ](https://github.com/farhanashrafdev/90DaysOfCyberSecurity)

8.  「awesome-mac」は、Mac上の様々な優れたソフトウェアを集めた、まさにMacユーザーにとっては宝の山のようなリポジトリだよ！🍎[🔗 プロジェクトリポジトリ](https://github.com/jaywcjlove/awesome-mac)

9.  「parlant」は、大規模言語モデル（LLM）のアプリケーションをシンプルにしてくれるLLMエージェントだよ！🤖 デプロイも使用も超簡単なんだ。[🔗 プロジェクトリポジトリ](https://github.com/emcie-co/parlant)

10. 「magic」は、AIエージェント、ワークフローエンジン、IM（インスタントメッセージング）、オンライン共同作業システムを統合した、オープンソースのAI生産性プラットフォームなんだ！🤔[🔗 プロジェクトリポジトリ](https://github.com/dtyq/magic)

11. DeepMindの主任科学者デニー・チョウ氏が、スタンフォード大学のCS25講義で大規模言語モデル（LLM）の推論メカニズムについて解説したよ！🤯 彼は、LLMの推論は一連の「中間トークン」を生成することによって実現されると指摘し、強化学習によるファインチューニングなどの技術についても深く掘り下げたんだ。[▶️ 動画デモ](https://www.youtube.com/watch?v=ebnX5Ur1hBk)

12. AIの安全性について、李飛飛氏とヒントン氏の間には異なる見解があるんだ。🤖 李飛飛氏は設計、ガバナンス、そして価値観に焦点を当てているのに対し、ヒントン氏は超知能の制御不能を懸念していて、人類を思いやるAIを設計すべきだと提唱しているよ。「目標の誤った一般化」と「ツールの収斂」は、AIが持つ潜在的なリスクの二大核心概念だね。

13. 「FormulaOne」は、なんとGPT-5のようなトップレベルの大規模モデルでさえ「大失敗」させ、全てのモデルがスコアゼロだったという新しいAI評価ベンチマークなんだ！🤔 220問のグラフ構造動的計画法問題を含んでいるよ。[FormulaOne](https://image.jiqizhixin.com/uploads/editor/656fe086-cbec-46b3-b135-a600f7a68fda/640.png) [🔗 FormulaOne リーダーボード](https://huggingface.co/spaces/double-ai/FormulaOne-Leaderboard)
