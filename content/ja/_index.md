## 猿思ネット洞察日報 2025/8/17

> `猿思 日報` 

### **AIコンテンツ概要**

```
Claude Codeは、AIへの依存によるスキル低下を防ぐ「学習モード」をローンチ。Googleは軽量な大規模モデルGemma 3 270Mをオープンソース化し、優れた性能と簡単な展開を実現。OpenAIの壮大な計画には、巨額投資やBMIなどが含まれ、アルトマン氏はAI発展が重要な時期にあると指摘。
新智元は10周年記念式典とASI時代の幕開けを迎え、AI関連人材を募集。Hi3DEval評価システムやAuto-RCAフレームワークなど、多数のオープンソースプロジェクトとAI技術応用の進展あり。
李飛飛とヒントンはAI安全リスクについて異なる見解を示し、前者はガバナンスに注目、後者は超知能の制御不能を懸念。新しいAI評価基準FormulaOneでは、トップクラスのLLMが「転倒」し、全モデルがゼロスコア。
```

### **今日AI资讯**

1. ✨ **Claude Code** が、AIへの長期的な依存による「AI脳萎縮」問題を解決するために、新しい **「学習モード」** をリリースしたよ！このモードは直接答えを教えるんじゃなくて、まるでプログラミングの「フィットネスパーソナルトレーナー」みたいに、重要なステップで一度立ち止まらせて、自分で手を動かしてタスクを完遂できるように導くんだ。これで本当にプログラミングスキルが身につくってわけ！

2. 🚀 **Gemma 3 270M** は、Googleがオープンソース化した軽量大規模モデル！たった270Mという少ないパラメータ数なのに、**指示への従順さ** や **テキスト構造化** のタスクで超優秀なパフォーマンスを発揮するんだ。一部のデカいモデルをも凌駕するレベルらしいよ。しかも低消費電力だから、スマホとかRaspberry Piみたいなデバイスでも動いちゃうし、軽くて速くてコスパ最高のAIアプリを作るのにピッタリなんだよね！

3. 🚀 **OpenAI** のCEO、サム・アルトマンが壮大な青写真を描いてるよ！数兆ドル規模の投資でデータセンターを建設したり、新型AIハードウェアを開発したり、なんと **脳機インターフェース** の分野にまで進出する計画だって！検索やソーシャルメディアをひっくり返そうとしてるみたい。彼は「今のAIはインターネットバブルの時みたいな、まさに分水嶺となる時期だ」と考えていて、GPT-5のリリースは「最高の時代であり、最悪の時代でもある」ことを象徴してるって言ってるんだ。

4. 🎉 **新智元** が10周年記念式典を迎えて、ASI時代の幕開けを祝ってるよ！それに合わせて、AI産業レポートの主筆、上級ビデオエディター、上級エディター/エディター、そしてエディターインターンなど、色んなポジションでAIが大好きな君の応募を待ってるんだ！ぜひ参加してみてね！[🔗 新智元の採用情報](此处应挿入新智元公式サイトの採用リンク、原文にはありません)

5. 🌟 **Hi3DEval** っていうのはね、上海AI研究所と複数の大学が共同で立ち上げた、もっと科学的で包括的な3D生成品質評価システムのことなんだ！これはオブジェクトレベル、パーツレベル、そしてマテリアルテーマの三層評価プロトコルを採用してて、3Dモデルの全体的な形、部分的な構造、素材のリアルさを多角的に分析してくれるんだよ。[🔗 Hi3DEvalプロジェクトページ](https://zyh482.github.io/Hi3DEval/) [🔗 3D生成リーダーボード](https://huggingface.co/spaces/3DTopia/3DGen-Leaderboard)

6. 🛠️ **build-your-own-x** っていうGitHubプロジェクト、知ってる？これはね、色んな技術をゼロから自分で構築するための学習パスを提供してくれてて、実際に手を動かしながらプログラミングスキルをマスターできるんだ！[🔗 プロジェクトリポジトリ](https://github.com/codecrafters-io/build-your-own-x)

7. 🔒 **90DaysOfCyberSecurity** は、なんと90日間でサイバーセキュリティを学ぶ計画を提供してるんだ！基礎的な認証から高度なテクニックまで、サイバーセキュリティのありとあらゆる側面をカバーしてるから、これから学ぶ人には超おすすめだよ！[🔗 プロジェクトリポジトリ](https://github.com/farhanashrafdev/90DaysOfCyberSecurity)

8. 💎 **awesome-mac** は、Macユーザーにとってまさに宝の山！Mac上のあらゆる種類の高機能ソフトウェアをたくさん集めてくれてるGitHubプロジェクトなんだ。Mac使いなら見逃せないよ！[🔗 プロジェクトリポジトリ](https://github.com/jaywcjlove/awesome-mac)

9. 🤖 **parlant** はね、大規模言語モデル (LLM) アプリケーションをシンプルにするためのLLMエージェントなんだ！デプロイも使うのもチョー簡単だから、LLMを手軽に活用したい人にはぴったりだよ！[🔗 プロジェクトリポジトリ](https://github.com/emcie-co/parlant)

10. ✨ **magic** は、AIエージェント、ワークフローエンジン、IM、オンライン共同オフィスシステムが全部ひとつになった、オープンソースのAI生産性プラットフォームなんだ！これ一つで作業効率が爆上がりしちゃうかもね！[🔗 プロジェクトリポジトリ](https://github.com/dtyq/magic)

11. 🧠 DeepMindの首席科学者デニー・チョウが、スタンフォード大学のCS25講義で **大規模言語モデル (LLM)** の推論メカニズムについて熱く語ってくれたんだ！彼が言うには、LLMの推論は一連の **中間トークン** を生成することで実現されてるんだって。さらに、強化学習によるファインチューニングみたいな最新技術も掘り下げてたよ。[▶️ ビデオデモンストレーション](https://www.youtube.com/watch?v=ebnX5Ur1hBk)

12. 🤔 **李飛飛とヒントン**、この二人の巨匠はAIの安全問題について意見が分かれているんだよね。李飛飛は **デザイン、ガバナンス、そして価値観** に重きを置いているんだけど、ヒントンはスーパーインテリジェンスが暴走することを心配していて、**人類を思いやるAI** を設計すべきだと提唱しているんだ。「目標の誤った一般化」と「ツールへの収斂」が、AIの潜在的なリスクにおける二大核心概念ってわけ。ちょっと考えさせられる話だよね。

13. 🤯 **FormulaOne** っていう新しいAI評価基準が登場したんだけど、これがすごくてね！220問のグラフ構造動的計画法問題が含まれてるんだけど、なんとGPT-5みたいなトップクラスの大規模モデルが軒並み「転倒」しちゃって、全モデルの成績がゼロ点だったんだって！これはAIの能力に一石を投じる結果だね！[FormulaOne](https://image.jiqizhixin.com/uploads/editor/656fe086-cbec-46b3-b135-a600f7a68fda/640.png) [🔗 FormulaOne リーダーボード](https://huggingface.co/spaces/double-ai/FormulaOne-Leaderboard)
