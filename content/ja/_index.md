## 猿思ネット洞察日報 2025/8/17

> 猿思 日報

### **AIコンテンツ概要**

```
Claude CodeがAI依存によるスキル低下を防ぐ「学習モード」をリリース。Googleは軽量な大規模モデルGemma 3 270Mをオープンソース化し、優れた性能と簡単なデプロイを実現。OpenAIは数兆ドルの投資、脳コンピューターインターフェースなど、壮大なビジョンを描いており、CEOのアルトマン氏はAI発展の重要な時期だと考えている。
新智元（Xinzhiyuan）は10周年を迎えASI時代に突入、AI関連の人材を募集中。Hi3DEval評価システムやAuto-RCAフレームワークなど、多数のオープンソースプロジェクトとAI技術の応用が進展。
李飛飛（フェイフェイ・リー）氏とヒントン氏はAI安全リスクに関して異なる見解を示し、前者はガバナンスを、後者はスーパーインテリジェンスの暴走を懸念。新しいAI評価基準FormulaOneは、GPT-5を含むトップクラスの大規模モデルを「失敗」させた。
```

### **今日のAIニュース**

1.  🤖🧠**Claude Code** が、AIへの長期依存による「AI脳萎縮」問題を解決するため、新しい**「学習モード」**をローンチしたよ。このモードは直接答えを出すんじゃなくて、まるでプログラミングの「フィットネスコーチ」みたいに、ユーザーが重要なステップで手を動かし、自分でタスクを完遂できるように導くんだ。これって、プログラミングスキルをマジで習得するためにめちゃくちゃ役立つよね！

2.  🐯🚀**Gemma 3 270M**、これはGoogleがオープンソース化した超軽量AIモデルなんだ！パラメーター数がたったの270Mしかないのに、**指示への追従**や**テキスト構造化**タスクでは、もっとデカいモデルを凌駕するパフォーマンスを発揮してるらしいよ。低消費電力だからスマホやRaspberry Piみたいなデバイスでも動いちゃうし、軽くて速くてコストも抑えられるAIアプリを作るのにピッタリじゃん！

3.  💰🌌**OpenAI**のCEO、サム・アルトマン氏が、OpenAIの壮大な未来図をぶっちゃけたよ！なんでも、データセンター建設や新型AIハードウェア開発に数兆ドル規模の投資を計画していて、なんと**脳コンピューターインターフェース**分野にまで進出し、検索やSNSをひっくり返す勢いなんだとか。彼は今がネットバブル期に似たAIの超重要な時期だと考えてて、GPT-5のリリースは「最高の時代であり、最悪の時代」の始まりを告げると言ってるよ。マジでヤバそう！

4.  🎉🥳**新智元（Xinzhiyuan）**が設立10周年を迎え、ASI（汎用人工知能）時代に突入したって！それを記念して、AI産業報道の主任記者、上級ビデオエディター、上級エディター/エディター、そしてエディターインターンなど、様々なポジションでAI好きの人材を大募集してるよ！興味ある人はぜひチェックしてみてね！[🔗 新智元の採用情報](此处应插入新智元官网招聘链接，原文未提供)

5.  😎**Hi3DEval**って知ってる？上海人工知能研究所が複数の大学とタッグを組んで、もっと科学的で包括的な3D生成品質評価システムを立ち上げたんだって！これ、オブジェクトレベル、パーツレベル、材質テーマの三段階評価プロトコルを使って、3Dモデルの全体的な形、局所的な構造、材質のリアルさを多角的に分析してくれる優れものなんだよ！[🔗 Hi3DEvalプロジェクトページ](https://zyh482.github.io/Hi3DEval/) [🔗 3D生成ランキング](https://huggingface.co/spaces/3DTopia/3DGen-Leaderboard)

6.  💪**build-your-own-x**っていうGitHubプロジェクトがマジで熱い！これは、色々な技術をゼロから構築するための学習パスを提供してくれるから、実践を通してプログラミングスキルをガッツリ習得したい人には超オススメだよ！[🔗 プロジェクトリポジトリ](https://github.com/codecrafters-io/build-your-own-x)

7.  🚀**90DaysOfCyberSecurity**ってプロジェクト、サイバーセキュリティを90日間で集中して学ぶプログラムを提供してるんだ！基礎的な資格から高度なテクニックまで、サイバーセキュリティのあらゆる側面を網羅してるから、かなり実践的だね！[🔗 プロジェクトリポジトリ](https://github.com/farhanashrafdev/90DaysOfCyberSecurity)

8.  🍎**awesome-mac**は、Macユーザーにとってのまさに宝の山！Mac用の素晴らしいソフトウェアがたっくさん集められているGitHubプロジェクトなんだ。Mac使いなら絶対チェックすべきだよ！[🔗 プロジェクトリポジトリ](https://github.com/jaywcjlove/awesome-mac)

9.  🤖**parlant**は、LLM（大規模言語モデル）のアプリケーションをめちゃくちゃシンプルにするためのLLMエージェントだよ。デプロイも使い方も超簡単だから、気になる人は試してみてね！[🔗 プロジェクトリポジトリ](https://github.com/emcie-co/parlant)

10. 🤔**magic**って、AIエージェント、ワークフローエンジン、IM、オンライン共同作業システムが全部一つになったオープンソースのAI生産性プラットフォームなんだって！これはもう、作業効率爆上げ間違いなしだね！[🔗 プロジェクトリポジトリ](https://github.com/dtyq/magic)

11. 🤯DeepMindのチーフサイエンティスト、デニー・ジョウ氏がスタンフォード大学のCS25講義で**大規模言語モデル（LLM）**の推論メカニズムを解説したよ。LLMの推論は、一連の**中間トークン**を生成することで実現されてて、強化学習によるファインチューニングなんかの技術についても深掘りしてたみたい！超興味深い！[▶️ ビデオデモ](https://www.youtube.com/watch?v=ebnX5Ur1hBk)

12. 🤖AIの安全問題について、李飛飛（フェイフェイ・リー）氏とヒントン氏の間で意見の相違があるみたいだね。リー氏は**設計、ガバナンス、価値観**に焦点を当てているのに対し、ヒントン氏はスーパーインテリジェンスの暴走を懸念して、**人類を思いやるAI**を設計すべきだと提唱してるんだ。「目標の誤った汎化」と「ツールの収束」が、AIの潜在的なリスクにおける二大核心概念らしいよ。
