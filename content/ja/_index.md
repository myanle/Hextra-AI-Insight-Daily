## 猿思ネット洞察日報 2025/8/17

> `猿思日報`

### **AIコンテンツ概要**

```
Claude Codeが「学習モード」を発表。AI依存によるスキル低下を防ぐ。Googleは軽量大規模モデルGemma 3 270Mをオープンソース化し、優れた性能と容易なデプロイを実現。OpenAIの壮大な計画には巨額投資やブレイン・マシン・インターフェースなどが含まれ、アルトマン氏はAI発展を重要な時期と捉える。
新智元は10周年記念式典と共にASI時代を開幕、AI関連人材を募集。Hi3DEval評価システム、Auto-RCAフレームワークなど、多数のオープンソースプロジェクトとAI技術応用が進展。
李飛飛氏とヒントン氏はAI安全リスクに関して異なる見解を持つ。李飛飛氏はガバナンスに注目し、ヒントン氏は超知能の制御不能を懸念。新AI評価ベンチマークFormulaOneでトップの大規模モデルが「転倒」。
```

### **今日のAIニュース**

1.  🤖 **Claude Code** の「学習モード」が新登場！AI依存による「AI脳萎縮」問題を解決するために開発されたんだ。直接的な答えを教えるんじゃなくて、まるでプログラミングの「フィットネスコーチ」みたいに、大事なステップで一旦立ち止まって、自分で手を動かしてタスクを完了させるようユーザーをガイド。これで、真のプログラミングスキルが身につくってわけ！

2.  🚀 **Gemma 3 270M** は、Googleがオープンソース化した超軽量大規模モデルだよ！パラメーター数はたったの270Mだけど、指令追従やテキスト構造化タスクでは、なんと大規模モデルを上回るパフォーマンスを発揮するんだ。低消費電力だから、スマホやRaspberry Piみたいなデバイスでも動いちゃう。軽くて速くて、しかも低コストなAIアプリ開発に超おすすめ！

3.  💸 **OpenAI** のCEO、サム・アルトマン氏がとんでもない未来図を語ってるよ！なんと数兆ドル規模の投資でデータセンターをバンバン建てて、新型AIハードウェアも開発、さらには「ブレイン・マシン・インターフェース」分野にも殴り込みをかけるんだって。検索やSNSを根っこからひっくり返す計画らしい。彼曰く、今はインターネットバブルと似たAIの超重要時期で、GPT-5の発表はまさに「最高の時代でもあり、最悪の時代でもある」ってことだ！

4.  🥳 **新智元** 10周年記念！ASI時代が幕開けだよ！新智元では、AI産業レポートの主筆、シニア動画編集者、シニアエディター／エディター、そしてエディターインターンなど、たくさんのポジションでAIが大好きな君の応募を待ってるよ！ぜひ仲間入りしてね！[🔗 新智元採用情報](此处应插入新智元官网招聘链接，原文未提供)

5.  ✨ **Hi3DEval** は、上海AI研究所が複数の大学とタッグを組んでリリースした、めちゃくちゃ科学的で超網羅的な3D生成品質評価システムなんだ。オブジェクトレベル、コンポーネントレベル、そしてマテリアルテーマという3層の評価プロトコルを採用して、3Dモデル全体の形、部分的な構造、素材のリアルさまで多角的に分析してくれるよ！[🔗 Hi3DEvalプロジェクトページ](https://zyh482.github.io/Hi3DEval/) [🔗 3D生成リーダーボード](https://huggingface.co/spaces/3DTopia/3DGen-Leaderboard)

6.  💪 **build-your-own-x** というGitHubプロジェクトが、いろんなテクノロジーをゼロから自分で構築する学習パスを提供してるよ！実践しながらプログラミングスキルを身につけたい人にぴったりだね。[🔗 プロジェクトリポジトリ](https://github.com/codecrafters-io/build-your-own-x)

7.  🚀 **90DaysOfCyberSecurity** は、ネットワークセキュリティの全てを網羅する90日間の学習プランを提供してるよ！基礎的な認証から、めちゃくちゃ高度なテクニックまで、これでサイバーセキュリティのエキスパートになれるかも！？[🔗 プロジェクトリポジトリ](https://github.com/farhanashrafdev/90DaysOfCyberSecurity)

8.  🍎 **awesome-mac** は、Macユーザーなら絶対チェックすべき！Macで使える素晴らしいソフトウェアがたくさん集められた、まさに宝の山みたいなGitHubプロジェクトだよ。[🔗 プロジェクトリポジトリ](https://github.com/jaywcjlove/awesome-mac)

9.  🤖 **parlant** は、大規模言語モデル（LLM）のアプリをもっとシンプルに使えるようにするLLMエージェントなんだ！デプロイも使うのも超簡単だから、ぜひ試してみてね。[🔗 プロジェクトリポジトリ](https://github.com/emcie-co/parlant)
