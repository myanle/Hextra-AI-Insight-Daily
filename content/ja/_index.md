## 猿思網インサイト日報 2025/8/17

> 猿思 日報

### **AIコンテンツ概要**

```
Claude Code は「学習モード」を導入し、AIへの依存によるスキル低下を防ぐ。Google は軽量な大規模モデル Gemma 3 270M をオープンソース化、優れた性能で導入も容易だ。OpenAI の壮大な計画は巨額投資や脳コンピューターインターフェースなどを網羅しており、アルトマン氏はAI開発が重要な局面にあると考えている。
新智元 は10周年記念式典とASI時代の幕開けを迎え、AI関連人材を募集中。複数のオープンソースプロジェクトやAI技術の応用が進展中だ。例えば、Hi3DEval 評価システムや Auto-RCA フレームワークなどが挙げられる。
Fei-Fei Li と Hinton はAIの安全リスクについて異なる見解を持っている。前者はガバナンスに焦点を当て、後者は超知能の制御不能化を懸念。新しいAI評価ベンチマーク FormulaOne は、トップクラスの大規模モデルを「失敗」させた。
```

### **今日のAIインサイト**

1.  `Claude Code` が新しい「学習モード」を発表したぞ！🎉 これ、AIに頼りすぎるとスキルが錆びついちゃう「AI脳萎縮」問題を解決するためのスグレモノなんだ。答えをポンと出すんじゃなくて、まるでプログラミングの「フィットネスコーチ」みたいに、重要なステップでユーザーを立ち止まらせて、自分で手を動かして課題をクリアできるように導いてくれるから、マジでスキルが身につく設計になってるんだよね！💪

2.  `Gemma 3 270M`、これはGoogleがオープンソース化した超絶軽量な大規模モデルなんだ！🚀 パラメーターはたったの270Mなのに、「指示に従う」とか「テキスト構造化」タスクでは、一部のデカいモデルを凌駕するパフォーマンスを見せてくれるってマジかよ？！😲 しかも消費電力が少ないから、スマホとかRaspberry Piとかでも動かせちゃうんだ。軽量・高速・低コストなAIアプリを作るならコレしかないね！📱✨

3.  `OpenAI` のCEO、サム・アルトマンがとんでもない野望をぶちまけたぞ！🌌 数兆ドル規模の投資でデータセンターをバンバン建てて、新型AIハードウェアを開発、さらには「脳コンピューターインターフェース」分野にも殴り込みをかけるってさ！🧠 検索やSNSを根底からひっくり返すつもり満々だね。アルトマン曰く、今はインターネットバブルに似たAIの超重要な時期らしいんだ。`GPT-5` のリリースは「最高で最悪の時代」の到来を告げるサインだってさ。マジかよ！💰🚀

4.  `新智元` はなんと10周年！おめでとー！🥳 `ASI` 紀元も幕開けしたんだってさ。今、AI関連の人材をバリバリ募集中みたいだから、興味ある人はチェックしてみて！ [新智元 採用情報](此处应插入新智元官网招聘链接，原文未提供)

5.  `Hi3DEval` っていうのはね、上海人工知能研究所がいろんな大学と一緒にリリースした、超科学的でめっちゃ網羅的な3D生成品質評価システムなんだ！✨ オブジェクトレベル、パーツレベル、マテリアルテーマの3段階で評価するプロトコルを使って、3Dモデル全体の形、細かい構造、素材のリアルさを多角的に分析してくれるんだって。スゴすぎない？ [Hi3DEval プロジェクトページ](https://zyh482.github.io/Hi3DEval/) [3D生成リーダーボード](https://huggingface.co/spaces/3DTopia/3DGen-Leaderboard)

6.  `build-your-own-x` っていうGitHubプロジェクト、知ってる？💡 いろんな技術をゼロから自分で作れるようになる学習パスを提供してくれてるんだ。実践しながらプログラミングスキルをガッツリ身につけたい人には超オススメだよ！ [プロジェクトリポジトリ](https://github.com/codecrafters-io/build-your-own-x)
